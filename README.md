# Personal Developer Portfolio

A responsive portfolio website built with vanilla HTML, CSS, and JavaScript — no frameworks, no libraries.

🔗 **Live Demo:** [utkarsha5.github.io/WebDevelopmentProject](https://utkarsha5.github.io/WebDevelopmentProject)

![Portfolio Screenshot](./Image_1.png)

## Features

- **Typewriter Animation** — Rotating text effect in the hero section using vanilla JS
- **Responsive Design** — Fully functional across desktop, tablet, and mobile
- **CSS-Only Dropdowns** — Multi-level nested navigation without JavaScript
- **Smooth Scroll** — Back-to-top button with smooth scrolling behavior
- **Skill Progress Bars** — Visual representation of technical skills
- **Mobile Hamburger Menu** — Pure CSS toggle menu for smaller screens

## Tech Stack

- HTML5
- CSS3 (Custom Properties, Flexbox, Media Queries, Animations)
- JavaScript (ES6)
- Font Awesome Icons
- GitHub Pages (Hosting)

## Run Locally

No build tools needed. Just open `index.html` in a browser:

```bash
git clone https://github.com/Utkarsha5/WebDevelopmentProject.git
cd WebDevelopmentProject
open index.html
```
